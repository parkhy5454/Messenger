# 메신저 (MVP)

웹 앱(PWA) 형태의 1:1 메신저입니다. Node.js + Express + Socket.IO + PostgreSQL로 만들었습니다.

## 구현된 기능
- 회원가입: 아이디·이름·이메일·비밀번호, 이메일 인증 코드(6자리, 10분 유효)
- 로그인: 아이디·비밀번호 (이메일 인증 완료 후 가능)
- 카카오 로그인: 카카오 개발자 앱 키를 넣으면 동작 (아래 설정 참고)
- 친구 추가: 아이디로 추가 (MVP에서는 즉시 친구 관계가 됩니다)
- 1:1 실시간 채팅: 메시지 저장, 최근 50개 기록 조회, 친구에게만 전송 가능
- 차단: 차단하면 친구 관계가 끊기고 서로 메시지를 보낼 수 없습니다
- 신고: 사유와 함께 신고 기록을 저장합니다 (관리자 화면은 아직 없음)
- PWA: 홈 화면에 추가하고 화면 파일을 오프라인에서도 열 수 있습니다

## 아직 없는 기능 (다음 단계)
- 그룹 채팅, 파일·사진 전송, 푸시 알림
- 종단간 암호화(E2EE), 휴대폰 인증, 관리자 화면
- 친구 요청·수락 절차, 메시지 읽음 표시

## 로컬에서 실행
1. PostgreSQL을 준비하고 DB를 만듭니다.
2. 패키지 설치: `npm install`
3. 환경 변수를 설정합니다. 예: `.env.example` 참고
   - Windows PowerShell: `$env:DATABASE_URL="postgres://..."; $env:JWT_SECRET="..."`
4. 실행: `npm start` → http://localhost:3000
5. SMTP를 설정하지 않았다면 인증 코드가 **서버 콘솔**에 출력됩니다.

## Render에 배포
1. 이 프로젝트를 GitHub 저장소(예: `messenger-app`)에 올립니다. `node_modules`는 제외됩니다.
2. Render → **New + → Blueprint** → 저장소 선택 → `render.yaml`로 웹 서비스와 DB가 만들어집니다.
3. 환경 변수 입력:
   - `SMTP_USER`, `SMTP_PASS`(Gmail 앱 비밀번호), `SMTP_FROM`
   - `KAKAO_REST_KEY`, `KAKAO_REDIRECT_URI` (카카오를 쓸 때만)
4. `JWT_SECRET`은 자동으로 생성됩니다.

## 카카오 로그인 설정
1. https://developers.kakao.com 에서 앱을 만듭니다.
2. **앱 키 → REST API 키**를 `KAKAO_REST_KEY`에 넣습니다.
3. **카카오 로그인 → 활성화**, **Redirect URI**에 `https://<서비스주소>.onrender.com/api/auth/kakao/callback`을 등록합니다.
4. **동의항목**에서 닉네임은 바로 설정할 수 있고, 이메일은 사업자 정보 등록 등 심사가 필요할 수 있습니다. 이메일이 없어도 카카오 계정은 가입됩니다.

> 카카오 로그인 흐름은 키가 없어서 아직 실제로 테스트하지 못했습니다. 키를 넣고 한 번 시험해 보세요.

## 보안 메모
- 인증 코드는 해시로 저장합니다. 비밀번호는 bcrypt로 저장합니다.
- 로그인 토큰은 30일 유효하며 브라우저 localStorage에 저장됩니다. 실서비스 전에는 짧은 만료와 갱신 토큰 방식으로 바꾸는 것을 권합니다.
- 카카오 로그인 후 토큰은 주소 뒤쪽 `#token=` 부분으로 전달됩니다. 화면이 열리면 바로 지워집니다.
- 실서비스 전에는 보안 점검(속도 제한, 입력 검증, 의존성 취약점 점검)을 받으세요.

## 무료 플랜 주의
- Render 무료 PostgreSQL은 생성 후 30일이 지나면 만료됩니다.
- 무료 웹 서비스는 접속이 없으면 잠들었다 깨어나므로 첫 접속이 느릴 수 있습니다.
